# Luwipi pedagogical visual sources

Visuals are selected by **pedagogical meaning**, not merely by matching “child + piano”. A posture visual must expose body/bench/arms/feet; a hand visual must expose the hand/fingers; animal art is only an association for auditory concepts.

## Posture
- **The Posture of School Children (1913), Fig. 64** — Wikimedia Commons — “No known copyright restrictions”. The source itself describes the figure as an *incorrect position at the piano without support for the feet*. Used as a comparison/reference, not as a model of correct posture.
- **Piano Lesson.jpg** — Wikimedia Commons — CC0 1.0. Used as an additional body/bank/keyboard reference.

## Hands
- **Human Hand Palm Inside Remix** — FreeSVG / OpenClipart — Public Domain / CC0. Used for finger awareness/numbering.

## Auditory associations
- **Elephant** — OpenClipart — Public Domain. Association for low/heavy sound; it does not teach posture.
- **Rabbit** — OpenClipart — Public Domain. Association for soft/light sound; it does not teach hand technique.

Do not add a web image merely because it looks attractive. Verify both teaching relevance and reuse rights first.
