# Luwipi

Web app de iniciação musical e piano para crianças.

## Primeira fase
- 2 a 4 anos: descoberta musical, ritmo e coordenação
- 5 a 8 anos: piano infantil com progressão guiada
- 24h de teste grátis
- Login com Google
- Ativação/pagamento via WhatsApp: +244 933 400 445

Construído com Next.js + TypeScript.
